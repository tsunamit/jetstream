    Keyboard shortcuts

    Tab moves focus. Enter activates focused buttons. Escape cancels dialogs/pending sequences and keeps the composer in Normal. The composer uses CodeMirror Vim (counts, operators, text objects, Visual/block, search, registers, macros, undo/redo, dot), not a Neovim runtime. Keymaps can be changed from the header.

    Keymaps

    Binding scopes and notation

    App navigation runs in navigator and chat. The reply is a separate window below chat. Use leader w h/j/k/l, Ctrl W then h/j/k/l, or direct Ctrl h/j/k/l. Direct Ctrl window moves also work while editing; leader sequences run only in Normal/Visual. Idle app leader/pane/Alt-history bindings also work in composer Normal/Visual; other editor keys belong to the bundled Vim engine. Chat mappings also run in chat Visual. Explicit legacy composerNormal aliases remain supported. Global runs in the main window, including reply, but never in a dialog. Picker mappings run in Query and Browse; plain Browse motions never replace query typing. Ctrl PageDown/PageUp changes collection. No letter mappings run in unrelated text fields. Composer Ctrl O/I/R/D/U always belong to Vim; Ex/search prompts never trigger app commands.

    To use Space as leader, enter <Space> in the Leader field below, then click Save keymaps. Press Space, r, d for recently done turns; Space, r, t for recent threads overall; Space, r, c for recent captain visits. Space w h/j/k/l moves between windows; Space w w cycles them. These leader sequences run in Normal mode. Command K on Mac (Ctrl Shift K on Linux) is a separate quick opener. Typing jk in composer Insert returns to Normal; configure it in Reply: enter composer normal.

    Use letters (gt), <leader>rd, <Space>, <Enter>, <C-w>h. C = Ctrl, A = Alt, M = Meta (Mac), S = Shift, D = platform primary. Separate alternatives with |. Empty means unmapped. Escape cancels; Tab and native editing shortcuts are reserved.

    Connect to Capy

    Remembered keys are encrypted by Electron safeStorage using macOS Keychain. If secure storage is unavailable, the connection is session-only.

    Forget removes this Mac’s saved key, not the API key at Capy. Revoke it separately at Capy if needed.

    Model for next message

    Applies when your next queued message is picked up. Saving sends nothing and leaves running work unchanged. This choice stays in this session until sent.

    Current reasoning and modes aren't reported by the API. Unspecified options are left to the server.

    Retrying an unconfirmed message keeps its original model and message ID.

    Daybreak isn't advertised by the catalog. Machine selection is unavailable: the API doesn't report the agent's host or offer workspace moves.
